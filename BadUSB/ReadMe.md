# BadUSB Scripts 🖱️⌨️

This folder contains BadUSB scripts for the Flipper Zero. BadUSB allows the Flipper to act as a USB keyboard and execute automated keystroke sequences.

## ⚠️ Warning

These scripts are for **educational purposes only**. Only use them on systems you own or have explicit permission to test. Unauthorized use may be illegal.

## Contents

### Demo Scripts
- **demo_windows.txt** - Demonstration script for Windows systems
- **demo_macos.txt** - Demonstration script for macOS systems

### Pranks
- **Change-Wallpaper.txt** - Changes desktop wallpaper
- **Change-System-Sounds.txt** - Modifies system sound settings
- **Rickroll-MaxVolume.txt** - Classic rickroll prank with max volume
- **System-Message.txt** - Displays a system message dialog

## Usage

1. Copy the desired `.txt` file to your Flipper Zero's SD card in the `badusb` folder
2. Navigate to **BadUSB** app on your Flipper
3. Select the script you want to run
4. Connect the Flipper to the target device
5. Execute the script
