# Flipper Music Player 🎵

This folder contains music files in Flipper Music Format (.fmf) that can be played on the Flipper Zero using the Music Player app.

## Contents

- **Chasing.fmf** - Chasing melody
- **Marble_Machine.fmf** - Marble Machine tune

## Usage

1. Copy `.fmf` files to your Flipper Zero's SD card in the `music_player` folder
2. Navigate to **Music Player** app on your Flipper
3. Select the song you want to play
4. Press play to hear it through the Flipper's piezo speaker

## File Format

FMF files contain:
- BPM (Beats Per Minute)
- Duration
- Octave
- Note sequences with timing

## Creating Your Own

You can create your own FMF files by:
1. Converting RTTTL (Ring Tone Text Transfer Language) format
2. Manually writing note sequences in the FMF format
3. Using community tools and converters
